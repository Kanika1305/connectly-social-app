# 🌐 Connectly - Social Media Web Application

Connectly is a full-stack social media web application that allows users to create accounts, log in, share posts, like posts, and comment on posts. The project is built using React.js, Node.js, Express.js, and MongoDB Atlas.

## 🚀 Live Demo

**Frontend:** https://connectly-social-app.vercel.app/

**Backend API:** https://connectly-backend-l4i2.onrender.com

## 📌 Features

- User Registration and Login
- Create Text Posts
- Public Feed
- Like Posts
- Comment on Posts
- Responsive UI
- MongoDB Database Integration
- Deployed Frontend and Backend

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/Kanika1305/connectly-social-app.git
```

### Backend Setup

```bash
cd backend
npm install
npm start
```



### Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

## 📷 Application Workflow

1. User creates an account.
2. User logs in.
3. User creates a post.
4. All users can view posts in the public feed.
5. Users can like posts.
6. Users can comment on posts.
7. Data is stored in MongoDB Atlas.
